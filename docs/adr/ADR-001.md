# ADR-001: Local-first vector store and switchable embedding and LLM providers

- **Status:** Accepted
- **Date:** 2026-09-30

## Context

The system must run on a student laptop with 8 GB of RAM, work offline for demos, and also be deployable to a small cloud instance. It needs metadata filtering (subject, document) for retrieval and page-level citations. Quality should be good enough to answer exam-style questions from lecture notes.

## Decision

1. **Vector store: ChromaDB** (persistent, embedded) via `langchain-chroma`.
2. **Embeddings:** local `sentence-transformers/all-MiniLM-L6-v2` by default. In production, use OpenAI `text-embedding-3-small`, selected by `EMBEDDING_PROVIDER`.
3. **LLM:** OpenAI (`gpt-4o-mini`) or a local 3B LLaMA through Ollama, selected by `LLM_PROVIDER`.
4. The embedding model id is stored in the Chroma collection metadata. The app refuses to query an index built with a different model (`INDEX_MISMATCH`) until it is rebuilt with `scripts/reset_index.py --reindex`.

## Options considered

| Option | Pros | Cons |
|---|---|---|
| **ChromaDB** (chosen) | No server; persists to disk; metadata `where` filters; stores documents with vectors | Single-process; heavier dependency than FAISS |
| FAISS | Very fast, tiny | No metadata filtering or document storage; ids and filters must be built by hand |
| pgvector / hosted vector DB | Scales, multi-user | Needs a server; overkill for a single-user project; costs money |

| Embeddings | Pros | Cons |
|---|---|---|
| **MiniLM local** (default) | Free, offline, 384-dim, fast on CPU | Pulls in PyTorch (~1 GB installed); too big for 512 MB cloud instances |
| **OpenAI small** (production) | Better quality, no local RAM | Costs per token; needs network and a key |

## Consequences

- Laptop users get a fully offline system (MiniLM + Ollama) or a cheap cloud-quality one (MiniLM + OpenAI).
- Production uses `requirements-prod.txt` without sentence-transformers or torch. Because models differ between environments, a local index cannot be copied to production; production builds its own.
- Switching models requires a reindex. The mismatch check turns a silent quality bug into an explicit error.
- Chroma plus SQLite on a disk limits the deployment to one instance, which is acceptable for a project demo.
